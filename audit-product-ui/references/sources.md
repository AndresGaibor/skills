## Uso de fuentes

Consultar solo la fuente que pueda cambiar un hallazgo. Priorizar W3C para requisitos, fuentes originales para estudios y sistemas de diseño para patrones contextuales. Citar sección/criterio y fecha de consulta en el reporte; evitar citas ornamentales. Revalidar cifras y recomendaciones cuando se afirme cumplimiento. El catálogo fue sintetizado el 4 de octubre de 2026 y no demuestra tasas de recurrencia por modelo.

La evidencia publicada sobre auditores multimodales es acotada (S04); no establece precisión de Sonnet, Opus ni esta skill. Baymard documenta su producto y dominio (S05), no valida cualquier prompt. Las señales visuales de Anthropic (S02) son orientación del proveedor, no prueba de autoría. Impeccable y UI UX Pro Max se consultaron como documentación pública; sus detectores no se ejecutaron.
