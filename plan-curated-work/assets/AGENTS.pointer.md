## Intercambio con el planificador

Para recopilar contexto, investigar, implementar o entregar evidencia de tareas
planificadas, leer `docs/agents/planner-handoff.md` y
`docs/agents/HANDOFF.json`. Confirmar proyecto y tarea antes de escribir.
El planificador solicita información y decide; este agente ejecuta únicamente
su encargo. Guardar respuestas por ID y publicar mediante los comandos
verificados de la configuración. Conservar cambios ajenos; respetar reservas
y la integración Git coordinada. No cerrar tareas sin aceptación del usuario.
